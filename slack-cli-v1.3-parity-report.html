02 / Delivered

CLI에 실제로 들어간 변화

전송 계층을 그대로 복제하지 않고, 한 번 실행되는 CLI에 맞는 계약으로 옮겼습니다.

Content integrity

메시지 본문이 더 이상 조용히 사라지지 않습니다

원문 text를 우선 보존하고, 빈 경우 Block Kit의 header·section·context·rich text에서 본문을 복구합니다. legacy attachment의 제목·필드·footer와 email 파일 메타데이터도 메시지 내용으로 유지합니다.

Channels

channels me

내가 속한 채널을 users.conversations의 native cursor로 조회합니다.

Discovery

채널 검색 대상 확장

name뿐 아니라 topic·purpose를 case-insensitive literal substring으로 검색합니다.

Reliability

검색 429 재시도

Retry-After를 따르며 최초 요청 후 최대 두 번만 재시도합니다.

Schema

사용자 ID 직접 조회

U...·W... 검색은 users.list 스캔 대신 users.info를 호출합니다.

Composition

blocks-only 전송

유효한 blocks가 있으면 messages post --payload의 text를 생략할 수 있습니다.

03 / Attachment

첨부파일 계약을 CLI답게 옮겼습니다

upstream은 본문을 MCP content로 즉시 반환합니다. CLI는 기존 metadata 기본 동작을 유지하면서 명시적인 content·save 모드를 추가했습니다.

Opt-in safety

최대 5 MiB,
명시적 활성화

다운로드 전 files.info의 크기를 검사하고, 실제 응답 크기도 다시 확인합니다. url_private_download를 우선 사용하고 url_private로 폴백합니다.

SLACK_MCP_ATTACHMENT_TOOL=true
또는 SLACK_MCP_ENABLED_TOOLS=attachment_get_data
default

메타데이터만 반환합니다. 파일 내용은 다운로드하지 않습니다.

--content

텍스트 MIME은 encoding: none, 나머지는 encoding: base64로 반환합니다.

--save

임시 디렉터리 0700, 무작위 파일명과 권한 0600으로 저장합니다.

difference

upstream의 native MCP image content는 CLI 전송에 없으므로 base64를 사용합니다.

06 / Boundary

이번에 하지 않은 것

누락이 아니라 현재 CLI 아키텍처와 인증 경계에 따른 의도적 제외입니다.

Auth boundary

Edge saved 도구

saved_*는 브라우저 세션 토큰 xoxc/xoxd와 비공개 Edge API가 선행 조건입니다.

Transport boundary

Native MCP image

CLI에는 MCP image content type이 없으므로 안전하고 이식 가능한 base64 결과를 제공합니다.

Architecture boundary

MCP 서버 lifecycle

현재 제품은 one-shot Bun CLI입니다. stdio·SSE·HTTP MCP 서버를 병렬로 추가하지 않았습니다.
